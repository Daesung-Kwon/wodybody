# G10. 측정 시트

상태: **템플릿 초안.** 참가자 실명·연락처를 넣지 않는다. 식별자는 가명(`P-001`)만. 시트 파일: [`G10-measurement-template.csv`](./G10-measurement-template.csv). 예시 두 줄은 가짜 숫자다.

기간: D1–D21 (완료 0 또는 1). 그룹은 `solo` 또는 `crew`. 크루가 아니면 `crew_id` 는 빈 칸.

## 1. 열

| 열 | CSV 이름 | 의미 |
| --- | --- | --- |
| A | `participant_id` | 가명 참가자 ID. 이메일·카카오·실명 금지 |
| B | `group` | `solo` 또는 `crew` |
| C | `crew_id` | 크루 가명. solo는 빈 칸 |
| D–X | `d1` … `d21` | 그날 크로스핏식 WOD 완료. 1=완료, 0=미완료. 빈 칸은 0으로 취급 |
| Y–AS | `difficulty_d1` … `difficulty_d21` | 그날 난이도 피드백. `easy` / `ok` / `hard` 또는 빈 칸 |
| AT | `shares` | 공유 횟수 (기간 합) |
| AU | `invites` | 그 참가자가 보낸 초대 수 |
| AV | `signups_via_invite` | 그 초대로 실제 가입한 수. 초대보다 클 수 없다 |

난이도는 완료 여부와 별도다. 완료 0이어도 "어려워서 못 함"이면 `hard` 를 적을 수 있다.

## 2. D7·D14 활성

정의: 그 체크포인트의 **직전 7일 완료가 2회 이상**이면 활성(1), 아니면 0.

- D7 활성: D1–D7 합 ≥ 2. 열 D–J.
- D14 활성: D8–D14 합 ≥ 2. 열 K–Q. (D1–D7을 다시 세지 않는다.)

구글 시트 2행(첫 데이터 행) 기준. 아래 두 열은 CSV에 없다. 시트에서 AW·AX로 추가한다.

```
AW2  active_d7   =IF(SUM(D2:J2)>=2,1,0)
AX2  active_d14  =IF(SUM(K2:Q2)>=2,1,0)
```

데이터 행 수만큼 채운다. 빈 참가자 행은 수식 범위 밖에 둔다.

활성 비율 (데이터 시작 행 2, 마지막 행 `last`):

```
D7 활성 비율  =AVERAGE(AW2:AWlast)
D14 활성 비율 =AVERAGE(AX2:AXlast)
```

예시 CSV의 `P-001`: D1–D7 = 1,1,0,1,0,1,0 → 합 4 → 활성. D8–D14 = 0 → 비활성.
`P-002`: D1–D7 합 2 → 활성. D8–D14 = 1,1,0,0,0,0,0 → 합 2 → 활성.

## 3. K

바이럴 계수 K는 참가자 한 명이 데려온 신규 가입이다.

```
K = (초대 수 합 / 참가자 수) × (초대로 가입한 수 합 / 초대 수 합)
  = 초대로 가입한 수 합 / 참가자 수
```

초대 합이 0이면 K는 빈 값이다. 0으로 나누지 않는다.

```
=IF(SUM(AU2:AUlast)=0,"",SUM(AV2:AVlast)/COUNTA(A2:Alast))
```

`COUNTA(A2:Alast)` 는 가명 ID가 있는 행만 센다. `signups_via_invite` 합이 참가자 수보다 해석상 어색하면(한 초대에 여러 가입) 그대로 둔다. K가 1보다 크면 한 명이 평균 한 명을 넘게 데려온 것이다.

예시: 가입 경유 합 0+1=1, 참가자 2 → K = 0.5. 초대 합 0+2=2 → 초대당 전환 1/2, 1인당 초대 2/2=1, 1×0.5=0.5.

그룹별 K가 필요하면 `group` 으로 필터한 뒤 같은 식을 쓴다. 크루 단위는 `crew_id` 로 필터한다.

## 4. 적는 규칙

- 하루에 완료는 최대 1.
- 공유·초대·경유 가입은 21일 합계다. 일별 열이 아니다.
- 시트에 연락처 열을 추가하지 않는다. 매핑표가 필요하면 운영자 기기 밖에 두지 않고, 2026-11-22 회의일부터 30일 이내 파기(G2)한다.
