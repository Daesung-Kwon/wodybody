# G3. 체지방 입력 — 민감정보 별도 동의 (제23조)

상태: **초안. 화면을 구현하거나 배포하지 않음.** 소유자·법률 검토 전이다. 결정 D2: 체지방 입력은 선택이고, 비공개이며, 동의한 뒤에만 저장한다.

개인정보 보호법 제23조는 민감정보를 원칙적으로 처리하지 못하게 하고, 정보주체 동의 등으로 예외를 둔다. 체지방률과 인바디 인쇄 이미지는 건강 관련 정보로 보고 별도 동의를 받는 전제로 이 초안을 썼다. 민감정보에 해당하는지는 법률 확인으로 확정한다.

가입 동의(G2)와 국외 이전 동의(G4)에 이 항목을 묶지 않는다.

## 1. 현재 코드 (동의 기록 없음)

- `burnfat/src/components/SubmitModal.tsx` 는 시작·종료 인증에서 체지방률(0–100)과 인바디 이미지를 **둘 다 없으면 저장하지 않는다.** 동의 행을 확인하지 않는다.
- 이미지는 비공개 버킷 `inbody` 에 `{participantId}/{type}-{timestamp}.jpg` 로 올라가고, 표시는 서버가 서명한 URL이다. 다른 참가자에게 숫자·사진을 숨기는 UI 강제는 이 초안 범위에서 코드로 재확인하지 않았다. 목표 동작은 §2와 같다.
- `weekly_logs.body_fat_rate`, `participants.target_body_fat` 는 스키마상 NULL이 가능하다 (`burnfat/src/types/index.ts`). 주간 기록은 비울 수 있으나, 그 값을 넣기 전에 동의 기록을 요구하는 검사는 없다.

즉 지금은 "동의 기록이 없어도 체지방이 저장될 수 있다." 아래 검사는 **제안**이며 적용하지 않았다.

## 2. 별도 화면

진입: 체지방 칸을 처음 누르거나, 인바디 사진을 고르려 할 때. 가입 마법사 안에 두지 않는다.

구성:

1. 제목: "체지방 정보 수집 동의 (선택)"
2. 본문:
   - 항목: 체지방률(%), 목표 체지방률, 인바디 등 측정 인쇄물 이미지
   - 목적: 본인의 변화 기록. 순위 계산에 쓸지는 소유자가 정한다. 크루·다른 참가자에게 숫자와 사진을 보이지 않는다.
   - 보관: 서비스 안 비공개 저장소. 국외 AI(xAI)로는 보내지 않는다(G4 최소화).
   - 거부: 거부해도 크로스핏식 WOD 기록·가입은 유지된다. 체지방 칸은 빈 값으로 남는다.
   - 철회: 설정에서 "체지방 정보 삭제"를 누르면 숫자와 이미지를 지운다.
3. 체크 한 개, 기본값 꺼짐: "위 내용으로 체지방 정보를 수집·저장하는 데 동의합니다."
4. 버튼 둘: "동의하고 입력" / "입력하지 않기". 체크 없이 "동의하고 입력"은 동작하지 않는다.

동의 시각, 방침 버전, 참가자 식별자만 동의 기록으로 남긴다. 동의 기록에 체지방 숫자나 사진을 넣지 않는다.

## 3. 저장 검사 (제안, 미적용)

규칙: **동의 기록이 없으면 체지방 관련 값을 쓰지 않는다.**

검사 순서:

1. 클라이언트가 체지방률, 목표 체지방, 인바디 이미지를 보내기 전에 동의 기록(참가자 id, 목적 `body_fat`, 동의 시각, 문서 버전)이 있는지 본다.
2. 서버(RPC 또는 Railway)가 같은 조건을 다시 본다. 클라이언트 검사만으로 통과시키지 않는다.
3. 기록이 없으면 `body_fat_rate`, `target_body_fat`, 인바디 객체 업로드를 거절하고, 사용자에게 "체지방 입력은 선택입니다. 동의 후에만 저장됩니다."를 보여 준다. 다른 필드(닉네임, 운동 횟수, WOD 완료)는 그대로 저장할 수 있다.
4. 철회 시 해당 참가자의 체지방 컬럼을 NULL로 지우고, `inbody` 버킷의 그 참가자 접두 객체를 삭제한 뒤 동의 기록에 철회 시각을 남긴다. 철회 시각만 감사 목적으로 남길지(숫자·이미지 없이)는 법률 검토로 정한다.

적용 시 손댈 곳으로 예상되는 것(이번 PR에서 수정하지 않음):

- `SubmitModal` 의 체지방·이미지 필수 검사 → 선택
- `weekly_logs` / `submissions` 를 쓰는 RPC
- 동의 테이블을 만드는 마이그레이션 (A12, 소유자가 적용)

검증 시나리오(구현 후, 프로덕션 데이터로 하지 않음):

- 동의 없이 제출 → 체지방 컬럼 NULL, 버킷에 새 객체 없음, 나머지 가입 정보는 있음
- 동의 후 제출 → 숫자·이미지 저장, 다른 참가자 화면에는 그 숫자·이미지가 없음
- 철회 후 재조회 → 숫자 NULL, 이미지 없음, 동의 없이 다시 저장 불가
