# G4. xAI 처리·국외 이전 고지와 최소화

상태: **코드 초안 (2026-10-28). 배포하지 않음. 환경변수·프로덕션 키는 바꾸지 않음.** PR #30 초안의 방향을 코드에 반영했다. 이전 국가·xAI 보관 기간은 아직 "[확인 전]"이다.

옵트인 기본값은 꺼짐.

## 페이로드

WOD (`recommendations.minimize_wod_context`, `_call_grok` 직전 적용):

- 남김: 난이도, 기구 목록, 가용 분(숫자), 완료 여부, 완료 분, 날짜, program id, 후보의 id·난이도·예상 분
- 뺌: goals 자유 기술, 프로그램 제목, 운동 이름, 닉네임, 사진, 체지방, `user_feedback` 원문 (`easy|ok|moderate|hard|skip` 만)

BurnFat 조언·코치 (`_build_user_content`):

- 남김: 주차, 운동 횟수, 수면, 식단 라벨(정상/과식/절식), 대결 날짜, 조언 목적·톤 화이트리스트
- 뺌: 닉네임, 나이, 성별, 체지방, 목표 체지방, 몸무게, 사진, `note`, `user_context` 원문
- 코치 장기 메모리 요약은 system 프롬프트에 넣지 않는다 (예전 요약에 체지방이 남을 수 있음)
- 코치 대화 문장 자체는 동의한 뒤에만 xAI로 간다. 고지 문구에 적혀 있다

`PROMPT_VERSION` 은 `g4-min-2026-10-28`. 체지방을 인용하던 이전 캐시는 읽지 않는다.

## 게이트

`request_has_xai_consent()`: 헤더 `X-Xai-Transfer-Consent: true` 또는 JSON `xai_transfer_consent: true`. 없으면 거짓.

- `POST /api/burnfat/ai/advice` 와 코치 `POST /messages` 는 403 `xai_consent_required`
- `GET /api/today`, refresh, recommendations generate 는 동의가 없으면 `_call_grok` 를 건너뛰고 폴백으로 고른다
- 스케줄러는 요청이 없으므로 xAI를 호출하지 않는다
- 화면: BurnFat AI 카드·코치, 오늘 화면의 "AI 추천 동의". 체크 기본 꺼짐. 철회는 localStorage 삭제
- 동의 시각 키: `wodybody:xai-transfer-consent`. DB 컬럼 없음

이 플래그는 실수로 호출되는 것을 막는다. 클라이언트가 값을 넣을 수 있으므로 서버에 남은 동의 원장은 아니다.
