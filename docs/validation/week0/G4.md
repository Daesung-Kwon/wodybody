# G4. xAI 처리·국외 이전 고지 (제28조의8)와 최소화

상태: **초안. 고지를 게시하거나 호출 코드를 바꾸지 않음.** 옵트인 기본값은 꺼짐. 이전 국가·수탁 계약은 소유자가 xAI 문서와 법률 검토로 확정한다. 이 초안은 xAI를 미국 사업자로 보고, 처리 위치가 미국 등으로 알려진 국외 이전으로 적는다. 정확한 국가·보관 기간은 xAI 약관에서 소유자가 베낀다.

근거 조문: 개인정보 보호법 제28조의8 (국외 이전). 고지에 보통 들어가는 요소는 이전받는 자, 이전 국가, 일시·방법, 항목, 목적, 보유·이용 기간, 거부 방법이다. 문안 확정은 법률 검토다.

## 1. 코드가 실제로 보내는 것

호출 URL은 세 곳 모두 `https://api.x.ai/v1/chat/completions` (환경변수 `XAI_API_KEY`). 사진 바이트를 붙이는 필드는 없다.

### 1.1 오늘의 WOD 추천 — `backend/routes/recommendations.py`

`_call_grok` (270–296행) HTTP JSON:

| 필드 | 값 |
| --- | --- |
| `model` | `XAI_MODEL` (기본 `grok-4-1-fast-non-reasoning`) |
| `messages[0]` | system: WOD 하나 고르는 코치 프롬프트 (`SYSTEM_PROMPT`, 43–70행) |
| `messages[1]` | user: 고정 문장 + `context` JSON |
| `max_tokens` | `XAI_MAX_TOKENS_RECOMMEND` 기본 300 |
| `temperature` | `0.6` |
| `response_format` | `{ "type": "json_object" }` |

`context` 는 `_build_context` (140–202행):

- `today` (날짜)
- `preferences.goals` (문자열 배열)
- `preferences.equipment`
- `preferences.available_minutes`
- `preferences.difficulty` (난이도)
- `recent_assignments[]`: `date`, `program_id`, `completed`, `skipped`, `user_feedback`, `intensity_hint`
- `recent_assignments_summary`: 7일 완료·스킵 횟수
- `recent_records_summary`: 30일 건수, 평균 완료 분, `last_5_records[]` (`date`, `program_id`, `completion_minutes`)
- `available_programs[]`: `id`, `title`, `difficulty`, `pattern_type`, `total_rounds`, `expected_minutes`, `exercises[]` (`name`, `reps`/`target_value`, `progression`)

`user_id` 는 DB 조회에만 쓰고 `context` 에는 넣지 않는다. 닉네임, 사진, 체지방, 이메일은 이 페이로드에 없다. `user_feedback` 은 자유 텍스트라 이름·연락처가 섞일 수 있다. 프로그램 `title`·운동 `name` 도 이용자가 지은 이름이면 마찬가지다.

### 1.2 BurnFat 주간 조언 — `backend/routes/burnfat_ai.py`

`_call_grok` (446–468행)은 system 프롬프트 + `_build_user_content` (366–401행) 문자열을 user 메시지로 보낸다. `max_tokens` 기본 700, `temperature` 0.7, `response_format` json_object.

user 문자열에 들어가는 항목:

- 닉네임 (`participant.nickname`)
- 나이, 성별, 목표 체지방률
- 대결 시작일·종료일
- 주간 기록: 주차, 체지방률, 몸무게, 운동 횟수, 수면, 식단 라벨, 특이사항 자유 텍스트(`note`)
- 이용자가 폼에 적은 조언 목적, 톤, 현재 상황(`user_context`)

이미지는 포함되지 않는다. 체지방·닉네임·몸무게·자유 기술은 포함된다.

### 1.3 BurnFat 코치 대화 — `backend/routes/burnfat_coach.py`

- 세션을 새로 열 때 시드 조언이 없으면 §1.2와 같은 `_build_user_content` 로 `_call_grok` 을 한 번 더 호출한다 (809행 근처).
- 본 대화 `_stream_grok` (432행 근처)는 system에 `_build_system_prompt` 를 넣는다. 그 안에 §1.2 user 내용, 장기 메모리 요약, 직전 어시스턴트 문장 일부가 들어간다 (517–567행). 이어서 최근 대화 턴과 이번 사용자 문장을 user/assistant 메시지로 보낸다.
- 세션을 닫을 때 `_call_grok_plain` (489행 근처)이 기존 메모리와 세션 대본을 보내 요약을 만든다 (960–964행).
- `_mask_pii` (148–152행)는 이메일·전화 패턴만 가린다. 닉네임·체지방·자유 텍스트는 가리지 않는다.

## 2. 최소화 제안 (코드 변경은 후속, 이번 문서에서 적용 안 함)

WOD 생성(§1.1)은 다음만 보낸다.

- 난이도(`preferences.difficulty`) — 레벨
- 기구(`preferences.equipment`)
- 기록: 완료 여부, 완료 시간(분), 날짜, 프로그램 id. 자유 텍스트 `user_feedback` 은 빼거나 `easy|ok|hard` 같은 정해진 값만

뺀다: 닉네임, 사진, 체지방, 나이, 성별, 몸무게, 이메일, `goals` 자유 기술, `user_feedback` 원문, 이용자가 지은 프로그램 제목에 이름이 들어갈 여지. 후보 프로그램을 골라야 하면 id·난이도·예상 분·기구 태그만 보내고, 제목 원문은 서버에 둔다.

BurnFat 조언·코치(§1.2, §1.3)도 같은 원칙이다. 국외로는 운동 횟수·수면·식단 라벨처럼 이미 범주화된 값만 보내고, 닉네임·체지방·몸무게·사진·`note`·`user_context` 원문은 보내지 않는다. 체지방을 조언에 쓰려면 G3 동의와 이 고지의 옵트인이 **둘 다** 있고, 법률 검토가 국외 전송을 허용한 뒤에만 예외로 둔다. 기본 제안은 체지방을 xAI에 보내지 않는 것이다.

코치 채팅 문장 자체도 국외로 간다. 옵트인 문구에 "대화 내용이 함께 전송된다"를 적는다. 거부 시 코치 대화와 AI WOD를 호출하지 않는다.
