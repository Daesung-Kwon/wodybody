## 이 PR이 넣는 코드 (배포 전)

- G3: `SubmitModal`, 주간 기록, 목표 체지방. 동의 없으면 숫자를 저장하지 않음. 동의 시각은 `localStorage` (`burnfat:body-fat-consent:<participantId>`). 다른 참가자 화면의 숫자는 이 기기의 device secret 이 있을 때만 표시. 방 코드 RPC는 여전히 숫자를 내려 준다
- G4: `recommendations.py` `minimize_wod_context`, `burnfat_ai.py` / `burnfat_coach.py` 본문 축소, `xai_transfer_consent` 없으면 xAI 미호출(스케줄러 포함). 장기 메모리 요약은 xAI로 보내지 않음. 코치 대화 문장은 동의한 뒤에만 전송
- 안내: BurnFat `/notice/privacy` 와 홈·대결방의 비차단 배너. 이메일·SNS 발송 없음
